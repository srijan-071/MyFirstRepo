# Git Workflow Checklist

Use this checklist for small experiments so the repository history stays easy to understand.

## Before editing

- Start from the current default branch.
- Read the relevant example or note before changing it.
- Define the smallest useful outcome for the change.

## Before committing

- Run the affected example when practical.
- Review the diff for accidental files, debug output, and machine-specific paths.
- Check that credentials and tokens are not present.
- Keep the commit focused on one coherent change.

## After committing

- Confirm the commit appears on the intended branch.
- Record a short note when the experiment teaches a reusable concept.
- If the change exposes a follow-up task, record it separately instead of mixing unrelated work into the same commit.
