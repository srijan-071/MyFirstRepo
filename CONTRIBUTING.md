# Contributing

MyFirstRepo is intentionally small, but changes should still leave a useful history.

## Good contributions

- Add a focused experiment that demonstrates a concept clearly.
- Improve an existing example without changing its purpose.
- Fix an incorrect explanation or broken example.
- Add concise notes that help reproduce an experiment.

## Commit checklist

Before committing:

- Keep the change focused.
- Remove credentials and local-only files.
- Test code examples when practical.
- Explain what changed and how it was verified.

There is no need to add complexity just to make a contribution larger.
